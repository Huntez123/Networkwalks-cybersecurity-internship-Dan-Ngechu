Week 01 — Cybersecurity Lab Setup

The first project involved creating a practical cybersecurity laboratory using Oracle VirtualBox and Kali Linux.

Key activities included:

- Configuring a VirtualBox NAT Network.
- Using the `10.0.0.0/24` subnet.
- Configuring Kali Linux with `10.0.0.2/24`.
- Configuring Internet connectivity.
- Enabling clipboard and drag-and-drop.
- Configuring a Windows-Kali shared folder.
- Troubleshooting the Kali network configuration.
- Creating a clean Kali Linux VM snapshot.
